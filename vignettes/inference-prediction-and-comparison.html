Inference, prediction and model comparison

This vignette covers what to do with a fitted model: which standard errors to use, how to predict and simulate, which residuals and diagnostics are available, and how to compare models, including when a likelihood-ratio (LR) test is valid and when it is not.

library(flexCountReg)
data("washington_roads")
d <- washington_roads

Standard errors

Every estimator has a stderr argument with three choices. The choice is made when the model is fit, and vcov(), summary(), confint(), tidy() and the delta-method standard errors of margEffTable() all use it.

  • "normal" (default): the inverse of the negative Hessian of the log-likelihood. It is valid when the model is correctly specified, including the count distribution.
  • "robust": the sandwich estimator. It remains valid for the mean coefficients when the distribution is misspecified but the mean model is right (quasi-likelihood). For panel models (countreg.rp() with group_var, renb(), poisLind.re(), repois(), negmultinom()) the log-likelihood has one contribution per panel, so these standard errors are cluster-robust.
  • "boot": a nonparametric bootstrap with bootstraps replicates. Rows are resampled for countreg(), and whole panels for panel models. Use it when the sample is small, when the Hessian is close to singular, or as a check of the other two.
f <- Total_crashes ~ lnaadt + lnlength + speed50
nb_h <- countreg(f, d, family = "NB2", method = "BFGS")
nb_r <- countreg(f, d, family = "NB2", method = "BFGS", stderr = "robust")
set.seed(1)
nb_b <- countreg(f, d, family = "NB2", method = "BFGS", stderr = "boot",
                 bootstraps = 50)
round(cbind(Hessian = sqrt(diag(vcov(nb_h))),
            robust = sqrt(diag(vcov(nb_r))),
            bootstrap = sqrt(diag(vcov(nb_b)))), 4)
#>             Hessian robust bootstrap
#> (Intercept)  0.4393 0.4855    0.4755
#> lnaadt       0.0518 0.0558    0.0541
#> lnlength     0.0694 0.0695    0.0674
#> speed50      0.1078 0.1142    0.1061
#> ln(alpha)    0.2487 0.2483    0.2304

Similar standard errors, as here, are reassuring. A robust standard error that is much larger than the Hessian one points to a misspecified distribution or dependence between observations.

The bootstrap uses only replicates whose refit converged and gave finite estimates. The number used is stored, with the reasons for any failures:

nb_b$model$n_boot_ok
#> [1] 50
nb_b$model$boot_failures
#> 
#>                error        not converged   wrong coefficients 
#>                    0                    0                    0 
#> non-finite estimates 
#>                    0

If many replicates fail, increase max.iters, try another method, or simplify the model. If fewer than two succeed, the standard errors are NA.

Weights. Every estimator takes weights, which are frequency weights: a row with weight 3 counts as three independent observations. The estimates, log-likelihood, robust covariance and BIC are those of the expanded data. In panel models the weights belong to the panels (a panel with weight 3 counts as three independent panels), so they must be constant within a panel. The bootstrap resamples the expanded observations: it draws new frequencies from a multinomial distribution and refits with them in place of the weights, so it needs whole-number weights (use stderr = "robust" for other weights).

Marginal effects

margEffTable() reports average marginal effects (or elasticities) with delta-method standard errors, or bootstrap standard errors with se = "bootstrap". For an indicator variable the default is the pseudo-elasticity, the percentage change in the expected count.

margEffTable(nb_h, digits = 4)
#> Marginal Effects / Elasticities
#> Method: delta 
#> 
#>      term variable_type           effect_metric estimate std_error t_value

#>  lnlength    continuous Average marginal effect   0.3511    0.0373  9.4194
#>   speed50     indicator   Pseudo-elasticity (%) -41.5523    6.3016 -6.5939

The bootstrap of margEffTable() resamples the model’s independent units (rows, or panels for panel models, or the clusters in cluster_var) and refits the model without an inner bootstrap.

Prediction

predict() returns one value per row of newdata, in order. Rows with missing values give NA; factor levels, contrasts and data-dependent bases such as poly() and splines::ns() are those of the training data; offset columns must be present.

For countreg() models, type chooses the quantity:

type Quantity
"response" (default) expected observed count
"true" expected true count (with underreporting)
"prob_reported" probability that a count is reported
"link" linear predictor \(X\beta\) + offset
"prob" matrix of \(P(Y = k)\), \(k = 0, \dots,\) max_count
"zero" zero-model probability (zero-inflated or hurdle models) 
nd <- d[1:3, ]
predict(nb_h, newdata = nd)
#> [1] 0.7798794 0.7097971 1.0432219
round(predict(nb_h, newdata = nd, type = "prob", max_count = 4,
              overflow = TRUE), 3)
#>          0     1     2     3     4    >4
#> [1,] 0.502 0.307 0.127 0.044 0.014 0.006
#> [2,] 0.531 0.301 0.116 0.037 0.011 0.004
#> [3,] 0.411 0.314 0.162 0.070 0.028 0.015

With overflow = TRUE the last column holds \(P(Y >\) max_count\()\), so each row sums to one.

For random-parameter models, method chooses how the random coefficients are handled:

  • "Simulated" (default): the average over Halton draws.
  • "Exact": the closed-form expectation (Wood and Gayah, 2025). It is not available, and the prediction is infinite, when the expected value does not exist (a lognormal random parameter with a positive variable, or a gamma random parameter beyond its moment-generating function’s domain); "Simulated" reports the same cases.
  • "Individual" (or "EB"): Empirical Bayes predictions that condition on each panel’s observed outcomes, so newdata must contain the outcome and the panel id. These are not forecasts for new units.

Negative multinomial models have method = "Standard" and "EB" in the same sense.

Fitted values, residuals and simulation

fitted() gives the predictions for the rows used in estimation, and residuals() the residuals of three types:

  • "response": observed minus fitted.
  • "pearson": divided by the standard deviation implied by the fitted distribution (countreg() models).
  • "quantile": randomized quantile residuals (Dunn and Smyth, 1996), which are standard normal when the model is correct; use them for residual plots and normality checks.
r <- residuals(nb_h, type = "quantile")
c(mean = mean(r), sd = sd(r))
#>         mean           sd 
#> -0.005664601  0.978277239

simulate() draws new responses from the fitted distribution for the same rows (with seed, reproducible and without changing the random-number stream of the session). It is the basis of parametric-bootstrap checks:

sims <- simulate(nb_h, nsim = 200, seed = 1)
# Observed share of zeros against its simulated distribution
c(observed = mean(d$Total_crashes == 0),
  simulated = mean(colMeans(sims == 0)))
#>  observed simulated 
#> 0.7335110 0.7307495

tidy(), glance() and augment() return tidy data frames, and rootogram() and cureplot() compare the fitted distribution and mean with the data (see the vignette on choosing a count distribution).

Comparing models

AIC and BIC

AIC and BIC compare any models fit to the same observations, nested or not, and are always reported. BIC uses the number of independent units: rows, panels for panel models, and the sum of the frequency weights when weights are used.

po <- countreg(f, d, family = "POISSON", method = "BFGS")
nb1 <- countreg(f, d, family = "NB1", method = "BFGS")
pl <- countreg(f, d, family = "PL", method = "BFGS")
do.call(rbind, lapply(list(Poisson = po, NB1 = nb1, NB2 = nb_h, PL = pl),
                      function(m) glance(m)[, c("logLik", "AIC", "BIC")]))
#> # A tibble: 4 × 3
#>   logLik   AIC   BIC
#> *  <dbl> <dbl> <dbl>
#> 1 -1101. 2209. 2230.
#> 2 -1089. 2188. 2215.
#> 3 -1085. 2180. 2206.
#> 4 -1086. 2182. 2209.

Likelihood-ratio tests

An LR test compares a restricted model with a larger one. The statistic \(2(\ell_\text{full} - \ell_\text{restricted})\) has its usual chi-square distribution only when:

  1. The models are nested. The restricted model is the larger model with some parameters fixed: the same estimator and model components, the restricted model’s parameters a subset of the larger model’s, and the same family or a nested family.
  2. The restriction is regular. The fixed values are inside the parameter space, every remaining parameter is identified under the restriction, and the restriction is not reached only in a limit.
  3. The data are the same. The same observations, outcome, offsets, weights and panels, and the same values of the variables both models use.
  4. Both fits reached their maximum. Both report convergence, and the larger model’s log-likelihood is not below the restricted model’s.

The families nest as follows:

Restricted Larger Restriction Null distribution
Poisson NB1, NB2, PLN, PIG1, PIG2, PIG dispersion = 0 50:50 mixture of \(\chi^2_{df-1}\) and \(\chi^2_{df}\)
Poisson GP1, GP2 dispersion = 0 \(\chi^2_{df}\)
Poisson COM \(\nu = 1\) \(\chi^2_{df}\)
NB1, NB2 NBP \(P = 1\) or \(P = 2\) \(\chi^2_{df}\)
PL PLG, PLL \(\alpha = 0\), \(\sigma = 0\) 50:50 mixture

For NB1, NB2 and the other families in the first row, a dispersion of 0 is on the boundary of the parameter space (a dispersion cannot be negative). The statistic then has a 50:50 mixture distribution, and the ordinary chi-square p-value would be twice too large.

These comparisons are not valid, and no p-value is reported:

  • Poisson vs PL, PLG or PLL. The Poisson-Lindley family does not contain the Poisson distribution: its variance is at least \(\mu + \mu^2/2\) for every \(\theta\).
  • Poisson vs NBP or SI. At the Poisson limit, NBP’s power \(P\) and the Sichel \(\gamma\) are not identified, so the usual asymptotics fail.
  • Poisson vs PW, PGE or GW. Their distributions approach Poisson only as a parameter goes to infinity.
  • A boundary family with a dispersion formula. The restriction sends an intercept to minus infinity while the slopes become unidentified.
  • Models with and without a zero model or underreporting. No zero inflation, or full reporting, is reached only in a limit (an intercept of minus or plus infinity on the logit scale).
  • Models with different random parameters. A random-parameter variance of zero is on the boundary, often with other parameters unidentified.
  • Non-nested models, such as NB1 vs NB2.

For these, compare models with AIC and BIC, or with a parametric bootstrap of the LR statistic using simulate().

summary() reports a test against Poisson when it is valid:

summary(nb_h)$lr_test
#> $statistic
#> [1] 31.31106
#> 
#> $df
#> [1] 1
#> 
#> $p.value
#> [1] 1.099119e-08
#> 
#> $logLik_poisson
#> [1] -1100.597
#> 
#> $boundary
#> [1] TRUE
is.null(summary(pl)$lr_test)   # no test: PL does not nest Poisson
#> [1] TRUE

When a condition fails, regCompTest() reports no LR test and gives the reason in LR_reason. Nesting of the mean model is checked on the design matrices, so y ~ x is nested in y ~ I(2 * x) + z.

regCompTest() applies the same rules to two fitted models (the one with fewer parameters is the restricted model) or to a model and a base model it fits on the same rows:

r <- regCompTest(po, model2 = nb_h)
r[c("LR", "LRdof", "LR_type", "LR_pvalue")]
#> $LR
#> [1] 31.31106
#> 
#> $LRdof
#> [1] 1
#> 
#> $LR_type
#> [1] "boundary"
#> 
#> $LR_pvalue
#> [1] 1.099119e-08
r <- regCompTest(nb1, model2 = countreg(f, d, family = "NBP",
                                        method = "BFGS"))
r[c("LR", "LRdof", "LR_type", "LR_pvalue")]
#> $LR
#> [1] 9.828608
#> 
#> $LRdof
#> [1] 1
#> 
#> $LR_type
#> [1] "interior"
#> 
#> $LR_pvalue
#> [1] 0.001718183

When the larger model has the lower log-likelihood, the larger model did not reach its maximum (check its convergence), and no p-value is given.

McFadden’s pseudo-R²

regCompTest() and regCompTable() report McFadden’s pseudo-R², \(1 - \ell / \ell_0\), against an intercept-only Poisson model on the same rows by default, so it is comparable across families. basemodel and variables choose another baseline.

regCompTable(list(Poisson = po, NB2 = nb_h))
